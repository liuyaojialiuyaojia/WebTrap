# WebTrap Injection

`web/psaa/` implements WebTrap injection for web-browser tasks. It reads an attack case, writes injected page metadata, and repackages the static site.

## Main Command

```bash
EXPERIMENT_ROOT=web/runs EXPERIMENT_ID=<run_id> \
  ATTACK_CASE=<attack_case.json> \
  INJECT_START_PAGE_PATH=/ \
  bash web/psaa/run_injection.sh
```

## Parameters

| Variable | Meaning |
| --- | --- |
| `EXPERIMENT_ROOT` / `EXPERIMENT_ID` | Experiment root to modify. |
| `ATTACK_CASE` | Attack-case JSON generated by `web/exp/04_task_gen`. |
| `PSAA_MODE` | WebTrap injection mode, default `dynamic`. |
| `PSAA_VARIANT` | `full`, `wo_lure`, `wo_inertia`, or `wo_payload`. |
| `PSAA_PROMPT_VERSION` | Prompt spec version, `base` or `enhanced`. |
| `PSAA_PROMPT_SPEC` | Direct YAML prompt-spec override. |
| `INJECT_START_PAGE_INDEX` / `INJECT_START_PAGE_PATH` | Dynamic injection start page. |

## Direct Entrypoints

```bash
python web/psaa/inject_from_attack_case.py --help
python web/psaa/pack_injected_site.py --help
```
